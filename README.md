## Features
- [x] Custom Reporter
- [x] Modern block editor with latest Blockly
- [x] Brand new extension system
- [x] Dark mode and many UI improvements
- [x] More, see our documentation, release notes and project board for details.

## How to Use
### 1. By Codingclip
We have our own community system that allows users to share projects created with ClipCC. Please visit [Codingclip](https://codingclip.com).
> Community version of ClipCC is still use old one, but we are planning to update it in the future.
### 2. Access our preview pages
We've set up preview pages for this repo that automatically update with the latest commits. For development branch, just see [ClipCC GUI](https://clipcc-preview.pages.dev/).
For specific branches, check pull request page's Cloudflare bot comments.
### 3. Use our desktop app
We provides stable desktop applications in [releases](https://github.com/Clipteam/clipcc/releases). For other installation methods like package managers, see [desktop's readme](./app/desktop/README.md).
### 4. Build from source
See [contributing guide](./CONTRIBUTING.md) for instructions on how to build ClipCC from source code.
